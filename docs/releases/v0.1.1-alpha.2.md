# Broadcasting Game Platform v0.1.1-alpha.2 — 보드 룸 생성 UI 테스트

테스트용 Windows x64 프리릴리스입니다. 정식 `v0.1.0` 및 기존 `v0.1.1-alpha.1`과 별도로 제공됩니다.

## 변경 내용
- 룸 생성 화면의 두 상위 패널 구조 유지
- **칸 효과**는 보드 설정 왼쪽에 항상 표시하며, **크기·모양**은 실제 보드 미리보기 오른쪽 상단에 배치
- 미리보기 아래의 두 버튼만 사용: **배치 / 이 배치로 확정**
- **배치** 버튼은 최초 실행 시 서버에 실제 룸 DRAFT를 만들고, 이후 누르면 기존 DRAFT를 재배치함
- 참가자 또는 보드 설정이 바뀌면 기존 배치를 무효화하고 새로운 DRAFT를 생성
- 실제 배치 확정 성공 시 방송용 룸 운영 페이지로 이동
- 생성 화면에서 OBS 주소 복사·새 창 열기, 시간 연장·일시정지·재개·룸 종료 같은 운영 UI 제거
- 참가자 아래의 중복 방송 상태 카드 목록 제거: 사진과 방송 상태가 위쪽 참가자 입력 행에 통합됨
- SOOP ID/표시 이름 변경 시 이전 프로필 사진과 상태 초기화, 상태에 마우스를 올리면 상세 결과 확인
- 최소 8×6, 기본 12×8 및 서버 기반 실제 보드 미리보기 유지
- 점유 중인 세로칸의 지시문 약 3글자 폭 제한과 여러 플레이어 세로 배치 유지

## 설치 및 테스트
1. `BroadcastingGamePlatformServer-Windows-x64-v0.1.1-alpha.2.zip`을 내려받아 별도의 테스트 폴더에 압축 해제합니다.
2. `BroadcastingGamePlatformServer/BroadcastingGamePlatformServer.exe`를 실행합니다.
3. 브라우저에서 `http://127.0.0.1:17832/admin/games/board/`로 접속합니다 (필요 시 관리자 승인).
4. 참가자를 입력하고 **배치**를 누르면 실제 서버가 생성한 보드가 표시됩니다.
5. 같은 **다시 배치** 버튼을 사용해 배치를 변경할 수 있습니다. 설정을 수정했다면 버튼은 다시 **배치**로 전환됩니다.
6. **이 배치로 확정**을 누르면 룸 관리 화면으로 이동합니다. 여기서 OBS 주소와 운영 기능을 사용합니다.
