# Broadcasting Game Platform v0.1.0

첫 플랫폼 분리 릴리스입니다.

## 주요 내용

- 기존 Roulette 저장소에서 보드게임 기능을 독립 플랫폼 저장소로 분리
- 플랫폼 랜딩 및 운영자 홈 추가
- 보드게임 룸 생성/운영 및 OBS 브라우저 오버레이 유지
- 6자리 룸 코드 기반 공개 오버레이 인증 유지
- 관리자 토큰/6자리 승인/12시간 세션 인증
- SOOP Provider 분리
- 채팅/후원 이벤트를 공용 Platform Event Bus로 정규화
- 공용 API `/api/v1/platform`, `/api/v1/providers`, `/api/v1/events/recent`
- Provider 범위 사용자 식별 구조 추가
- 향후 CHZZK Provider 확장을 위한 인터페이스/DB 기반 추가
- Windows x64 독립 실행 패키지 제공

## Windows 실행

압축을 해제하고 `BroadcastingGamePlatformServer.exe`를 실행합니다.

기본 주소:
- 플랫폼 서버 관리: http://127.0.0.1:17830/
- 플랫폼 랜딩/운영 UI: http://127.0.0.1:17832/
- WebSocket: 17831

최초 실행 시 `config.json`이 자동 생성됩니다.
운영 데이터베이스는 기본적으로 `data/platform.db`를 사용합니다.
