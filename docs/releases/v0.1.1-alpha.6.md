# Broadcasting Game Platform v0.1.1-alpha.6 — 다중 음성 TTS 기반 확장

Windows x64 프리릴리스입니다. 기존 alpha.5와 정식 릴리스는 변경하지 않습니다.

## 주요 변경
- **Windows SAPI + 선택형 eSpeak NG**: 두 로컬 TTS 엔진의 설치 음성 목록을 병합. eSpeak NG는 사용자가 별도 설치해 실행 경로(PATH)에 있을 때만 자동 인식합니다. **배포본에 외부 엔진/음성 모델을 동봉하거나 자동 설치하지 않습니다.**
- **추가 엔진 확장:** 신뢰하는 Java classpath 서비스 제공자(SPI) 기반 `TtsEngineRegistry`; 중복/오류가 있는 선택형 엔진은 격리합니다.
- **음성 메타데이터:** 언어·엔진·성별(엔진에서 제공될 때)·스타일·출처. 관리자 음성 실험실의 언어·엔진 필터에서 선택 가능합니다.
- **기본 설정 영속화:** 기본 음성 ID, 속도, 음량을 애플리케이션 폴더의 `tts-settings.json`에 원자적으로 저장. 서버 재시작 이후에도 유지됩니다.
- 설정 파일이 손상된 경우 원본을 보존하고 안전한 기본값으로 복구하여 **게임 서버 시작을 방해하지 않도록 처리**합니다.
- 음성 실험실에서 목소리 검색/선택, 발화 샘플 생성, 브라우저에서 WAV 미리듣기, 기본 설정 저장/복원 및 대기열 비우기 지원.
- 기존 TTS 기반의 단일 작업 워커와 제한된 음성 생성 대기열 유지.
- 게임, 채팅, 후원, OBS 자동 낭독 기능은 **연결하지 않았습니다.**

## 테스트 방법
1. 별도 폴더에 Windows ZIP을 압축 해제하고 `BroadcastingGamePlatformServer/BroadcastingGamePlatformServer.exe`를 실행합니다.
2. 인증된 관리자 브라우저에서 `http://127.0.0.1:17832/admin/tts/`에 접속합니다.
3. 설치된 목소리의 엔진·언어 필터를 전환하고, 다른 음성을 선택해 합성/미리듣기를 확인합니다.
4. **현재 값을 기본 설정으로 저장**을 누른 후 서버를 다시 실행해 음성·속도·음량 복원을 확인합니다.
5. eSpeak NG를 사용하려면 운영자가 해당 프로그램을 별도로 설치하고 서버를 다시 실행하거나 음성 목록을 새로 검색해야 합니다. eSpeak 음성이 없더라도 기존 Windows 음성은 정상 작동해야 합니다.
6. 모든 시스템에 한국어 SAPI 음성이 제공되는 것은 아니며, eSpeak 음색은 Windows SAPI와 차이가 있을 수 있습니다.
