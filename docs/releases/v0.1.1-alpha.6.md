# Broadcasting Game Platform v0.1.1-alpha.6 — 다중 음성 기반 확장

Windows x64 테스트용 프리릴리스. 기존 v0.1.1-alpha.5 및 정식 버전을 덮어쓰지 않습니다.

## 새 기능
- Windows SAPI 외에 **eSpeak NG** 로컬 엔진을 선택적으로 지원합니다. `espeak-ng`가 기존 PC의 PATH에 설치된 경우에만 해당 음성을 노출하며, 아무것도 자동 다운로드/설치하지 않습니다.
- **Java SPI** 기반 엔진 레지스트리 추가. 서명/검증된 앱 빌드 클래스패스에 포함된 제3의 엔진 구현을 추후 연결할 수 있도록 하고, Windows shaded JAR에서도 서비스 선언 파일을 병합합니다.
- 음성 카탈로그에 언어, 알려진 성별, 스타일과 설치 출처 메타데이터를 포함합니다. OS/엔진이 알려주지 않는 값은 추측하지 않습니다.
- `/admin/tts/`에서 **언어별 필터 / 엔진별 필터**, 음성 정보 표시, 기본 목소리·속도·음량 저장 및 저장값 불러오기를 지원합니다.
- 기본값은 실행 폴더의 `tts-settings.json`에 원자적으로 저장됩니다. 음성 파일, 시험 문장, 작업 내역은 저장하지 않습니다.
- 저장한 목소리가 제거되면 알림을 표시하고, 손상된 설정 파일로 인해 플랫폼 전체가 시작되지 않도록 방어합니다. 기존 손상 파일은 직접 저장하기 전까지 유지합니다.
- 기존 비동기 합성 큐와 관리자 전용 WAV 미리듣기를 유지합니다.
- **게임 / 채팅 / 후원 / OBS 자동 출력 연계는 아직 구현하지 않았습니다.**

## 설치 및 확인
1. ZIP을 별도 폴더에 압축 해제하고 `BroadcastingGamePlatformServer/BroadcastingGamePlatformServer.exe`를 실행합니다.
2. 관리자 인증 후 `http://127.0.0.1:17832/admin/tts/`에 접속합니다.
3. '목소리 다시 검색'을 눌러 시스템에 실제 설치된 음성을 찾습니다. SAPI의 사용 가능 음성은 사용자 PC별로 다릅니다.
4. 언어/엔진 필터로 목소리를 좁혀 선택하고, 시험 문장을 입력해 음성 생성 및 미리듣기를 확인합니다.
5. **현재 값을 기본 설정으로 저장**을 누른 뒤 서버를 재시작하여 음성·속도·음량이 복원되는지 확인합니다.
6. eSpeak NG 설치가 없으면 eSpeak 목소리가 표시되지 않습니다. 선택형 설치는 플랫폼에서 제공하지 않습니다.
