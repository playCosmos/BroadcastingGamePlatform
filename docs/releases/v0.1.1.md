# Broadcasting Game Platform v0.1.1 — TTS Foundation

## Included

- Standalone administrator-only **TTS voice laboratory** at `http://127.0.0.1:17832/admin/tts/` after administrator authentication.
- Multi-voice catalog: native Windows SAPI, optional eSpeak NG, optional Piper ONNX neural speech, and trusted Java ServiceLoader adapters.
- Voice language/engine filtering, speaker selection, rate/volume controls, sample speech synthesis, WAV playback and persistent voice defaults.
- Bounded asynchronous synthesis: 16 pending jobs, 24 job records, 5 MiB WAV/request, 16 MiB retained preview audio and 15-minute preview expiry.
- Fault-isolated external speech processes, per-engine timeout/cleanup, WAV framing validation, and administrator-origin protection.
- **No** chat, donations, games, providers, or OBS auto-speaking integration. Existing Board / Drawing Guess / Viewer Draw behavior is preserved from `main` at release branch creation. The unrelated changes in draft PR #25 are **not** included.

## Verification

- Windows app packaging, browser checks and Java regression probes, including authenticated TTS HTTP API/CSRF probes.
- Windows SAPI actually synthesized WAV using Microsoft David Desktop in CI.
- Linux CI actually synthesized WAV using eSpeak NG and checksum-pinned Piper ONNX English test voice.
- The three local engines and all third-party voices are optional. No external voice engine, model, or voice pack is bundled or downloaded by the running app.

## Windows operator quick-start

1. Download `BroadcastingGamePlatformServer-Windows-x64-v0.1.1.zip` and its `.sha256` file. Check the archive checksum using `Get-FileHash -Algorithm SHA256 <archive>`.
2. Extract into a **new directory**; do not overwrite an existing running application's `data/`, `config.json`, or `tts-settings.json`.
3. Run `BroadcastingGamePlatformServer.exe` from the extracted `BroadcastingGamePlatformServer` folder.
4. Authenticate using the locally displayed administrator bootstrap link, then browse to `http://127.0.0.1:17832/admin/tts/`.
5. Click **새로고침** if needed, select any installed Windows SAPI voice, enter text, click to synthesize and use the HTML audio player to listen.
6. Test Korean text, mixed English/digits, speed and volume; save defaults and reload. When only English desktop voices exist, add a Korean voice in Windows or separately install eSpeak NG / Piper.
7. If you independently install Piper, place matching `.onnx` and `.onnx.json` files in `tts/voices/` under the application's root (never in `web/`). Use only voice packs with licenses permitting your intended use.

## Limitations

Windows SAPI lists traditional System.Speech desktop voices and may not list OneCore voices. eSpeak NG must be on PATH before launching the platform; Piper must be on PATH and have a valid model/config pair. TTS output is for **administrator preview only** and is not forwarded to games or broadcasters. Preview audio is never stored across app restarts. Manual voice quality varies by installed voice/model and language.

This is one **consolidated** TTS foundation release. The former `v0.1.1-alpha.5`, `alpha.6`, and `alpha.7` TTS releases and tags remain deleted; board-related `alpha.1`–`alpha.4` remain unchanged.
