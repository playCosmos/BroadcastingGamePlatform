# Broadcasting Game Platform v0.1.1-alpha.7 — Piper 다중 음성 확장 테스트

Windows x64 테스트용 프리릴리스입니다. v0.1.1-alpha.6과 기존 버전은 유지합니다.

## 추가 사항
- 기존 Windows SAPI 및 선택형 eSpeak NG에 더해 **Piper 로컬 신경망 TTS 어댑터** 추가
- 설치된 `piper` 실행 파일(PATH)을 검색하며 모델은 오직 플랫폼 실행 폴더의 `tts/voices/`에 관리자가 직접 배치한 파일만 읽음
- `*.onnx`와 짝을 이루는 `*.onnx.json` 메타데이터를 탐색, 언어 및 다중 화자(`speaker_id_map`)별 목소리 ID 구성
- 음성 목록의 기존 엔진·언어 필터와 목소리 기본값 저장 기능 그대로 사용
- Piper 길이 배율로 속도 조절, 합성된 16비트 PCM WAV 샘플에 한해 음량 조절
- 모델 경로·심볼릭 링크·설정 크기 제한과 손상된 WAV 방어, 최대 64모델 탐색
- 게임/채팅/후원/OBS 자동 낭독 **연결 없음**

## Windows 사용 방법
1. ZIP을 별도 폴더에 압축 해제하고 플랫폼 서버를 실행합니다.
2. 관리자 인증 후 `http://127.0.0.1:17832/admin/tts/`에서 SAPI 목소리로 기본 기능을 확인합니다.
3. **Piper를 사용하려는 경우에만**, 신뢰할 수 있는 출처에서 Piper 실행 파일을 별도로 설치하고 실행 파일이 `PATH`에서 `piper` 명령으로 실행되는지 확인합니다. 이 프리릴리스는 Piper 실행 파일을 포함하지 않습니다.
4. 음성 모델의 **라이선스를 검토**하고 `BroadcastingGamePlatformServer/tts/voices/` 디렉터리를 생성하여 모델 파일과 동일한 이름의 JSON 설정 파일을 함께 복사합니다.
   - 예: `tts/voices/ko_KR-example-medium.onnx`
   - 예: `tts/voices/ko_KR-example-medium.onnx.json`
   - 예시 이름은 파일 배치 규칙을 나타낼 뿐, 특정 모델이 제공된다는 의미는 아닙니다.
5. 서버에서 **목소리 다시 검색**을 누릅니다. 발견된 Piper 목소리를 선택해 문장을 생성하고 직접 미리들어 봅니다.
6. 다중 화자 모델에 `speaker_id_map`이 있으면 화자별 목소리가 목록에 나타납니다.

## 제약
- 모델 및 바이너리 **자동 다운로드·설치·삭제 기능 없음**. 모델 파일과 Piper 실행 파일은 사용자가 직접 준비해야 합니다.
- 모델별 한국어 품질, Piper CLI 버전, Windows 설치/실행 호환성은 실기 테스트가 필요합니다. eSpeak NG 음성 품질과 Piper 신경망 모델 품질은 다릅니다.
- Piper 생성 음성은 지원되는 PCM WAV 파일일 때만 음량 처리가 가능하고, 지원하지 않는 형식이면 작업에 실패한 것으로 표시합니다.
- 기본 음성 설정만 `tts-settings.json`에 보존하며, 발화 텍스트·생성 오디오·작업 정보는 저장하지 않습니다.
- 인증된 관리자만 음성 생성 및 재생 API를 사용할 수 있습니다.
