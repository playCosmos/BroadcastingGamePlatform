# Broadcasting Game Platform v0.1.1-alpha.4 — 칸 효과 편집 UX 테스트

Windows x64 테스트용 프리릴리스. 기존 `v0.1.1-alpha.3`과 정식 `v0.1.0`은 유지됩니다.

## 변경 사항

- 칸 효과의 **표시 문구를 제목 입력창에서 바로 수정**합니다. 수정 시 효과 목록과 아래 이동 효과 제목도 즉시 연동됩니다. 중복 입력창은 제거됩니다.
- **랜덤** 칸 효과를 체크 가능한 기본 효과로 추가했습니다. 신규 룸에서는 기본 비활성입니다.
- 랜덤 효과를 활성화하면 랜덤 후보 선택 방식이 나타납니다. 기본값은 직접 선택이며, 다른 효과의 `랜덤 후보에 포함` 체크 항목도 이때 표시됩니다.
- 랜덤 후보를 선택하면 해당 효과 속성의 맨 아래에 **랜덤 가중치** 입력창이 나타납니다. 비활성 또는 미선택 후보에서는 숨겨집니다.
- 사용자 지시문 추가 버튼은 목록 위에 고정하고, 효과 목록은 **최대 4개만 표시하며 내부 스크롤**합니다.
- 실제 보드 배치 제목과 보드 정보는 한 줄로 표시하며, **정보 글꼴 크기는 유지**하고 제목만 약간 확대했습니다.
- '배치 / 다시 배치' 버튼에는 손그림풍 회전 화살표, '이 배치로 확정'에는 체크 표시 아이콘을 추가했습니다.
- 기존 룸의 실제 서버 DRAFT 생성/재배치/확정과 설정 저장·불러오기 기능은 유지됩니다.
- 최소 8×6, 기본 12×8 유지. 세로칸 플레이어와 지시문 배치 제약은 변경하지 않습니다.

## 테스트 방법
1. ZIP을 새 폴더에 압축 해제하고 `BroadcastingGamePlatformServer/BroadcastingGamePlatformServer.exe`를 실행합니다.
2. `http://127.0.0.1:17832/admin/games/board/` 로 접속합니다.
3. 칸 효과에서 첫 번째 '앞으로'를 선택해 **상단 제목을 수정**하고, 왼쪽 목록과 아래 이동 설정의 문구가 동일하게 바뀌는지 확인합니다.
4. '랜덤'은 처음 비활성 상태입니다. 활성화 후 다른 효과에서 `랜덤 후보에 포함`을 선택하면 맨 아래에 가중치가 나타나는지 확인합니다. 서버에서 랜덤 효과를 배치하려면 랜덤 후보를 하나 이상 지정해야 합니다.
5. 사용자 지시문을 추가해도 추가 버튼이 제자리에 있고 목록의 5번째부터 스크롤되는지 확인합니다.
6. 오른쪽 실제 보드 정보가 제목 옆 한 줄로 나타나는지 확인한 후, 배치/다시 배치/확정 버튼을 사용해 실제 서버 보드를 확인합니다.
