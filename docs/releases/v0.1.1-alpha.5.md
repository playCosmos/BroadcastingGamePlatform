# Broadcasting Game Platform v0.1.1-alpha.5 — 독립 공통 TTS 기반

Windows x64 테스트용 프리릴리스. 기존 v0.1.1-alpha.4 이하 릴리스는 유지됩니다.

## 새 기반 시스템

- 플랫폼 운영 홈에 **공통 TTS · 음성 실험실** 추가: `/admin/tts/`
- 현재 Windows에 실제 설치된 목소리 목록을 확인하고 목소리·속도·음량을 선택하여 시험 문장을 합성하고 WAV로 미리듣기
- `TtsService.TtsEngine` 추상화와 여러 엔진의 음성 카탈로그 병합 지원. 추가 음성 엔진 및 음성팩을 위한 기반.
- 비동기 순차 합성, 대기열 최대 16건, 최근 작업 최대 24건, WAV 최대 5MiB, 문장 최대 200자, 합성 프로세스 30초 시간 제한
- 관리자 전용 API: `/api/v1/tts/voices`, `/status`, `/speak`, `/jobs/{id}`, `/jobs/{id}/audio`, `/queue`
- 목소리 다시 검색 기능; Windows PowerShell + `System.Speech` 엔진은 외부 라이브러리/클라우드 서비스 없이 실행.
- 음성 테스트 외 **SOOP·게임 이벤트 연결 없음**, 공개 방송 오버레이 자동 TTS 출력 없음. 음성팩 설치/다운로드는 추후 단계.

## 설치 및 테스트

1. Windows ZIP을 기존 버전과 별도 폴더에 풀고 `BroadcastingGamePlatformServer/BroadcastingGamePlatformServer.exe`를 실행합니다.
2. 운영자 인증 후 `http://127.0.0.1:17832/admin/tts/`를 엽니다.
3. 시스템에 설치된 음성을 목록에서 선택합니다. 기본으로 한국어 음성이 있으면 우선 선택합니다.
4. 시험 문장을 입력하고 **음성 생성**을 누릅니다.
5. 합성 완료 후 **음성 미리듣기**의 재생 버튼으로 직접 테스트합니다.
6. 음성 추가 설치 후 **목소리 다시 검색**을 누르면 목록을 갱신할 수 있습니다.
7. 시스템에 지원되는 음성이 설치되지 않았다면 목록이 비어 있습니다. **기본 배포본은 음성 모델이나 음성팩을 함께 설치하지 않습니다.**

## 제한 및 보안

- TTS 생성과 WAV 조회는 인증된 관리자 세션으로만 허용됩니다. 게임·후원·채팅 데이터를 자동으로 낭독하지 않습니다.
- 사용자 입력/음성 데이터는 서버 재시작 시 유지되지 않으며, 기본적으로 로그/DB에 저장하지 않습니다.
- Windows 설치·로그온 사용자에 따라 SAPI 음성이 없거나 한국어 음성이 지원되지 않을 수 있습니다. 실제 음질·엔진 목록은 **사용자 PC에서 테스트**해야 합니다.
- 이 프리릴리스는 미래의 다중 엔진을 위한 구조이지만, **현재 실제 합성 엔진은 Windows 기본 음성 엔진 하나**입니다.
