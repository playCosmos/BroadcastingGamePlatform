# Broadcasting Game Platform v0.1.1-alpha.3 — 룸 생성 화면 편집 개선 테스트

테스트용 Windows x64 프리릴리스입니다. `v0.1.1-alpha.2`를 덮어쓰지 않으며, 정식 릴리스 `v0.1.0`도 유지됩니다.

## 이번 업데이트
- 참가자 행에서 삭제/방송 상태 버튼을 해당 입력칸의 아래쪽에 맞춰 정렬합니다.
- 보드 크기·모양의 4개 입력 항목은 공간이 충분하면 한 줄로, 부족하면 두 줄로 나눕니다.
- 이동방식의 주사위 설정 1줄, 윷 설정 1줄로 높이를 줄이고 상단 플랫폼 홈 버튼 간격을 정돈합니다.
- 칸 효과 편집기에서 내부 효과 **ID를 숨깁니다**. API, 프리셋 저장, 서버 내부 식별에는 기존 ID가 유지됩니다.
- `{n}`은 이동 칸 수, `{m}`은 다음 던지기에 적용할 이동 배수라는 설명을 추가합니다.
- 배치 비율은 **서버와 동일한 계산 방식**으로 예상 배치 칸 수를 표시합니다. START를 제외하고 고정 수량 배치를 먼저 배정한 뒤, 남는 칸에서 비율을 적용하며 소수점은 최대 잔여법으로 분배합니다.
- 최소 8×6, 기본 12×8, 실제 서버 DRAFT 기반 미리보기와 배치/확정 흐름을 유지합니다.
- 이전 v0.1.1-alpha.2의 참가자 행 프로필 사진·상태 통합과 운영 버튼 제거를 유지합니다.

## 테스트 방법
1. `BroadcastingGamePlatformServer-Windows-x64-v0.1.1-alpha.3.zip`을 다운로드해 **기존 설치와 다른 폴더**에 압축 해제합니다.
2. `BroadcastingGamePlatformServer/BroadcastingGamePlatformServer.exe` 실행 후 `http://127.0.0.1:17832/admin/games/board/`에 접속합니다.
3. 참가자 삭제/방송 상태 버튼의 수직 정렬과 주사위·윷 한 줄 배치를 확인합니다. 브라우저 폭을 줄여 반응형 배치를 확인합니다.
4. 보드 크기 12×8에서 기본 `{n}칸 앞으로`/뒤로 효과를 각각 선택합니다. 기본 설정의 고정 효과가 3칸이므로, **비율 10%의 예상 배치 수는 각각 3칸**이어야 합니다.
5. 8×6에서는 각각 2칸, 16×12에서는 각각 5칸을 예상합니다. 수량 배치·비율·활성화 설정을 바꾸면 안내도 갱신됩니다.
6. 룸 생성 화면에서 **배치 → 다시 배치 → 이 배치로 확정** 흐름을 확인합니다. 확정 후 운영 페이지로 이동합니다.
