# Broadcasting Game Platform v0.1.1-alpha.1 — 보드 지시문 가독성 테스트

**프리릴리스 / 테스트용.** v0.1.0 정식 릴리스를 대체하지 않습니다.

## 변경 내용
- 실제 보드 지시문의 글자 크기, 명도, 글자 두께 및 제한된 줄바꿈 개선
- 최소 보드 8×6, 기본 보드 12×8 유지
- 플레이어가 있는 세로칸은 지시문/플레이어를 좌우로 분리하고, 지시문은 기존 **한 줄 약 3글자** 제한 유지
- 같은 세로칸에 모인 여러 플레이어의 세로 방향 배치 유지
- 게임 규칙, 서버 배치 생성 및 방 확정 절차는 변경하지 않음

## Windows x64 설치 및 테스트
1. 이 릴리스의 `BroadcastingGamePlatformServer-Windows-x64-v0.1.1-alpha.1.zip`을 내려받아 압축 해제합니다.
2. 압축 해제된 `BroadcastingGamePlatformServer/BroadcastingGamePlatformServer.exe`를 실행합니다.
3. 브라우저에서 `http://127.0.0.1:17832/`를 열어 서버 UI에 접속합니다.
4. **플레이 테스트:** `http://127.0.0.1:17832/games/board/index.html?demo=1&cols=8&rows=6&players=6`
5. **사각 보드:** `http://127.0.0.1:17832/games/board/rect.html?demo=1&cols=8&rows=6&players=6`
6. 기본 크기 비교: 위 주소의 `cols=8&rows=6`을 `cols=12&rows=8`로 변경합니다.
7. 실제 룸 배치를 시험하려면 운영 UI의 `/admin/games/board/`에서 룸 초안을 생성하고 **실제 보드 미리보기**를 확인합니다.
