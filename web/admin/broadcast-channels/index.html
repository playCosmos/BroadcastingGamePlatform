게임룸 및 방송 지정

운영자는 방송인에게 해당 채널 사용 허가를 받은 뒤 발급해야 합니다. 이 기능은 SOOP 계정 소유권을 자동 확인하지 않습니다. 게임룸 가입이나 비로그인 플레이에는 영향을 주지 않습니다.

발급 토큰 — 이 화면에서만 표시됩니다.

게임룸 방장에게 안전한 경로로 전달하세요. 토큰은 지정된 방·채널에만 사용 가능하며, 한 번 사용하면 재사용할 수 없습니다.

게임룸 ID를 입력하고 승인 상태를 조회하세요.

게임룸별 연결 및 미사용 승인 토큰

미사용 토큰은 만료 시간만 표시하며 원문을 다시 조회할 수 없습니다. 회수는 해당 방·채널의 미사용 토큰과 이미 연결된 채널을 모두 해제합니다.
