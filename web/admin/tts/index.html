로컬 Piper 음성팩 관리

서버의 tts/voices에 ONNX와 ONNX.JSON 파일을 직접 배치한 뒤 등록하세요. 자동 다운로드·파일 업로드·모델 삭제는 지원하지 않습니다.

최초 등록 시 관리 모드가 활성화되어 등록되지 않은 기존 Piper 음성은 사용되지 않습니다. 각 음성을 순서대로 등록하세요.

로컬 모델 목록을 불러오는 중입니다.

등록 해제는 관리 목록에서만 제거하며, ONNX/JSON 파일은 삭제하지 않습니다. SHA-256은 Windows에서 Get-FileHash -Algorithm SHA256 <파일>, Linux에서 sha256sum <파일>로 확인할 수 있지만 반드시 신뢰할 수 있는 배포처의 값과 대조해야 합니다.

음성 미리듣기

문장을 생성하면 아래에서 직접 재생할 수 있습니다.

현재는 관리자 수동 테스트 전용입니다. 음성 프로필은 로컬 tts-profiles.json에 저장됩니다. 채팅·후원·게임 이벤트 연결, OBS 자동 낭독 및 음성 팩 설치 기능은 구현하지 않았습니다. Windows 내장 음성 외에도 별도로 설치된 eSpeak NG와 Piper의 음성을 사용할 수 있습니다. Piper의 ONNX 모델 및 대응 JSON 파일은 서버의 tts/voices 폴더에 직접 배치해야 합니다. 지원 음성이 없으면 합성할 수 없습니다.
